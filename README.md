# 城市旅行 Agent

面向不自驾的城市自由行用户，将想去的地点整理为有数据依据的行程，并在延误、天气变化或偏好改变后协助调整。

本仓库目前处于实施规划阶段，尚未实现应用代码。

## 初版目标

- 杭州、1～3 天、步行与公共交通，用户提供已经确定的酒店和抵离信息。
- 支持必去地点、固定预约、每日时间范围与旅行节奏。
- 使用地点、路线及天气工具补充事实，由规划器排程、校验器检查明确约束。
- 提供地图、时间轴、活动锁定、调整预览与版本恢复。
- 通过固定数据评测和真实用户试用验证效果。

## 实施文档

- [初版实施计划](docs/IMPLEMENTATION_PLAN.md)：范围、架构、数据模型、接口、开发里程碑、评测与验收标准。

## 拟采用的技术栈

后端 Python / FastAPI / Pydantic，前端 React / TypeScript / Vite，持久化 PostgreSQL / SQLAlchemy / Alembic，Agent 编排采用 LangGraph。地图、地点、路线与天气优先接入高德；具体接口权限在实施第一阶段验证。

首个应用骨架建立时再锁定依赖版本并补充启动步骤。
