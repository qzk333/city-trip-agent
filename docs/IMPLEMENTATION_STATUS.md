- React / TypeScript / Vite 工作台，支持桌面与手机尺寸。
- 国家/地区、省份/州/行政区、城市三级联动与城市检索；按目的地当地时区安排 1～3 天行程。
- 杭州保留 10 个夹具，其他城市使用明确的示意占位活动；配置用户高德 Key 后可查询当前城市真实 POI。默认天气保持未知。
- FastAPI、Pydantic 输入校验、SQLAlchemy 持久化与 0001/0002 Alembic 迁移；保留历史杭州行程。
- LangGraph 的候选选择 → 排程 → 独立校验链路。
- 启发式排程：固定预约分段、候选插入、往返住处路线、衔接余量与休息空档。
- 固定预约、营业时间、必去地点、路线连续性、返回住处边界的独立校验。
- 区分直接约束冲突、数据待确认与当前搜索预算内未找到方案。
- 未确认预览、幂等确认、版本并发检查、取消预览、历史恢复。
- 以日为单位的延误、室内优先、可选活动移除与活动锁定/解锁；未调整日期冻结。
- 延误偏移随行程版本保存，多次延误累加。
- 任务查询、存储的阶段事件与 SSE 游标回放。
- 模型模式：允许列表内的目录/说明工具调用，最多 4 轮模型请求、6 次目录工具执行，最终校验候选 ID。
- 高德城市 POI、坐标转换、路线与天气适配；旅行绑定独立地点快照。
- 网页填写用户模型/高德凭据，支持连接测试、Key 遮蔽、标签页存储与清除。
- 每次请求独立配置，网页不继承服务器 API Key，不把用户凭据写入数据库或行程；公开模型端点使用公网 IP 固定连接。
- 可选浏览器地图 Key 改为网页填写，不再从构建环境注入。
- 路线调用次数和总时间预算；无 Key、无路线与接口故障不静默回退演示数据。
- Windows 安装与启动脚本、锁定依赖、CI 配置、固定数据评测入口。

## 验证边界

- 演示目录中的地点坐标和时间为夹具或占位；真实 POI 来自本次高德查询，但营业、预约、活动属性及停留时间仍未全面核验。
- 地理目录覆盖全球，不代表当前高德标准接口的全球覆盖。中国大陆以外只开放目录选择与示意排程。
- 地图和模型接口代码已有本地测试；尚未配置凭据进行真实服务在线验证。
- 模型协议测试使用 HTTP 模拟响应，不能据此声称某个真实模型已兼容。
- 默认使用 SQLite。PostgreSQL 连接与迁移路径保留，尚未运行真实 PostgreSQL 集成测试。
- 当前后台任务运行在 API 进程内。重启会把中断任务标为失败，用户重试；尚未实现独立 worker、租约或持久化图检查点。
- 当前图没有自动多轮修复规划冲突的循环；冲突由校验报告展示，用户修改条件后重新规划。
- 锁定、删除等操作为结构化卡片交互；未实现自然语言对话、攻略地点自动抽取及会话摘要。
- 表单固定预约是示例入口；后端 Schema 支持多项预约，前端任意预约编辑器尚待完善。
- 途中调整使用整日开始时间偏移，没有当前实际位置和“已完成活动”输入；不能替代真实途中导航。
- 尚未实现交通站点抵离、预约库存、完整园内步行、预算约束与路线搜索的全局最优。
- 页面处于本地个人使用范围，未实现公开服务的多用户认证。
