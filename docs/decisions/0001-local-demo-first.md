# 决策 0001：先交付可运行的本地链路

日期：2026-10-23。

## 背景

当前机器有 Node 和可用 Python 3.12，没有 PostgreSQL 或 Docker。项目尚未配置地图、模型 Key，也没有经过核实的旅行数据。

## 决策

1. SQLite 用于本地运行和测试；SQLAlchemy 保持数据库抽象，保留 PostgreSQL 驱动和 Alembic 迁移。真实 PostgreSQL 的并发行为另行验证。
2. `TOOL_PROVIDER` 与 `PLANNING_MODE` 独立设置：可以分别验证真实路线工具或模型工具调用。缺少真实模式所需凭据时返回明确错误，不自动降级。
3. 演示模式保持天气未知，路线和地点时间明确为夹具；所有计划保留待确认提示。
4. 先用确定性规划器与独立校验器打通链路，模型只参与候选工具查询和排序。修复循环、独立 worker 和自然语言会话安排在后续阶段。
5. 版本只有经过用户确认后才更新，固定数据演示也走相同的预览、校验、提交与恢复路径。

## 影响

无需外部凭据即可调试交互和失败场景。当前结果只能证明软件链路及特定夹具上的行为，不能证明真实旅游质量或真实模型效果。
