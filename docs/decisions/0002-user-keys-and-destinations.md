# 决策 0002：目的地目录与用户自带 API

日期：2026-10-23。

## 需求

通过国家、省份/州/行政区、城市三级选择目的地。模型及高德凭据由访问者自行提供，不能让网页请求消耗项目维护者的 API 额度。

## 实现

- 在仓库固定地理数据快照，后端按行政区返回城市；前端按需查询，避免把全量城市打入页面资源。
- 城市使用稳定的来源 ID；创建旅行时服务端核对国家、行政区和城市归属，补全规范名称与时区。
- 杭州保留既有夹具；其他城市的演示活动明确为占位。真实高德查询单独生成目录快照，绑定城市 ID。
- Trip 保存这次使用的地点目录，规划器、模型目录工具、校验器和版本恢复都读取同一快照，禁止修改共享杭州全局目录。
- 模型和地图模式、Key 由每次请求的配置头传入；复制为本次任务专用 Settings，不覆盖全局 Settings。
- 无配置文件时默认为演示，不继承 `.env` 凭据。环境变量用于数据库、服务预算、本地文件路径和命令行显式测试。
- 根据用户最新要求，API 配置改为项目本地 `.local/api-config.json`；整个目录被 Git 忽略，空模板单独提交。网页保存采用原子替换，重启从文件恢复；不再把 Key 写入浏览器存储。旧浏览器配置仅在没有本地文件时迁移，迁移成功后才清理旧副本，失败保留 Key 供重试。
- 本机配置接口限制 loopback 连接与 Host/Origin，返回 no-store。普通本机请求由服务端读取文件，远程请求不继承文件凭据。模型和 Web 服务 Key 不写入数据库、任务事件或行程响应；JS Key 和安全密钥只用于浏览器地图 SDK。
- 自定义模型地址限制为公开 HTTPS/443。服务端校验 DNS 地址，并将请求固定到已校验的公网 IP；TLS SNI、Host 保留原域名，禁止重定向。
- SQLite 启动时执行 Alembic 迁移；只对能够识别的旧版自动建表结构补记 0001，再升级至 0002。用户历史行程沿用杭州目录后备。

## 边界

全球地理目录不代表高德标准接口的全球覆盖。当前真实查询接入中国大陆服务；境外只开放目录选择与示意排程。

真实 POI 查询不代表营业时间、预约、室内外属性和游玩时长均已核实。建议停留及活动属性仍以估算标记。

用户凭据隔离不等于完整的多用户身份认证。本次没有增加账号、旅行访问权限或公开部署；这些仍是公开服务前的独立工作。

## 数据来源

地理快照来源、固定版本、转换方式与 ODbL 许可见 `data/geography/ATTRIBUTION.md` 和 `provenance.json`。上海市中心为有明确注释的本地参考点补充；常见城市显示名存在独立的界面别名。
