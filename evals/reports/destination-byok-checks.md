## 本次验证内容

1. 国家与行政区联动，上海和东京目的地可选择、生成和刷新恢复。
2. 目的地更换后旧地点清空，城市归属不一致及混用其他城市地点会被拒绝。
3. 高德目录快照绑定城市；模型工具、规划器、校验和版本使用本次旅行的地点目录。
4. 模型、高德 Key 在当前标签页保存和清除，字段默认遮蔽，不写入 localStorage。
5. 网页默认请求不继承服务端模型或地图凭据；两次请求中的用户 Key 独立，服务器原配置不被覆盖。
6. 旅行与地点目录数据库不保存 API Key；模型用量只保留非负整数，不保存提供方返回的任意文本。
7. 模型地址拒绝内网、非 HTTPS、账号及查询参数；公网传输保留 TLS SNI/Host、固定已验证 IP，不跟随重定向。
8. 无效配置和提供方认证错误不会在用户响应中回显 Key。
9. SQLite 0001 → 0002 迁移与模型结构一致，现有本地数据库启动已升级，旧杭州旅行可继续读取。

## 验证限制

真实地图发现、模型鉴权、连接测试响应与网络传输分支使用模拟 HTTP 数据。没有使用维护者的 API Key，也没有验证某个真实用户的服务权限或额度。

地理目录来自固定社区数据快照，城市名称与坐标不是已核实旅游资料。海外目的地当前仅支持示意排程。新功能没有补齐公开部署的用户认证和旅行访问控制。
