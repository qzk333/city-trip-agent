# 三日攻略、分段交通、高德排队与地图放大

日期：2026-10-23。

## 修复依据

原排程把每个候选的路线查询放在整日异常块内，首个无路线结果就可能中断当天；候选数量较少时又未给后续日期保留活动。公交接口还误用了 adcode，官方要求 city 为城市名或 citycode。

官方参考：[路径规划](https://lbs.amap.com/api/webservice/guide/api/direction)、[错误码说明](https://lbs.amap.com/api/webservice/guide/tools/info)。公开搜索使用 [DDGS](https://github.com/deedy5/ddgs) 的 Bing 后端，不要求用户额外配置搜索 Key。

## 结果

- 108 项后端测试、28 项桌面/手机浏览器流程通过；TypeScript、生产构建、Prettier、Ruff 通过。
- 自建状态回归集 10/10 通过。
- 验证少量候选分配到三天、无公交方案的替代方式、临时导航失败的明确估时、每一天完整往返、来源 ID 校验与无私网跳转。
- 高德同 Key 跨任务并发测试确认网络请求最大同时数为 1；模拟时钟验证最小间隔、共享缓存、QPS 重试上限及日额度不重试。
- 使用本机配置和当前城市地点快照完成实际在线生成：三天各 3 个活动，6 个攻略来源，3 条有来源的交通建议，12 段路程全部取得高德查询结果，0 个排程错误，约 35.31 秒。保留营业/预约/交通估计的待确认提示。
- 实际攻略检索中读取到 1 个页面片段，其余保留为搜索摘要；并未声称读取全部完整攻略。
- 使用同一在线结果和实际高德 JS SDK 检查桌面/手机地图弹层：真实底图正常，3 个日期、6 个来源链接、无页面异常、无横向溢出。
- 个人行程与版本未被测试覆盖，在线结果及截图写入忽略的 `artifacts/`；测试未打印真实 Key。

## 限制

攻略只用于候选顺序、按天分组和参考交通，不作为营业、库存、班次或价格的可靠证明。导航失败的距离估时单独标记；原地图虚线仍为地点连接示意。当前限流器为单服务进程内共享，多实例部署需替换为共享限流。免费公开搜索可能受网站访问或反爬影响，失败不虚构来源。
