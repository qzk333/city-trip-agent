## 数据与边界

候选与选择保存至 proposal / version 的 itinerary JSON；独立执行记录保存至 `agent_tasks`。老行程缺少 lodging_mode 时按 fixed 解释，保留原来的往返住处语义。

高德接口提供酒店地点资料，其消费参考字段不能用作某入住日期的报价。本轮没有房价、库存、房型、退款政策或在线预订功能；候选交通时间明确标为直线距离估算，用户选择后再查询导航。接口依据：[高德搜索 POI 官方文档](https://lbs.amap.com/api/webservice/guide/api/search/)。

当前仍是受控 LangGraph 流程：固定检索与 Provider 调用，专项模型独立分析，程序校验与版本确认；没有动态多轮自主分工或服务重启后的自动续跑。
